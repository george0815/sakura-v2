This document goes over the major libraries that are used in this repo.

- Nes_Snd_Emu - https://github.com/blarggs-audio-libraries/Nes_Snd_Emu 

Used for emulating the NES APU. I'm not as interested in the APU as I am in the other components, so just as with the original sakura I will just write a wrapper. 


- FTXUI  - https://github.com/ArthurSonzogni/FTXUI

Used to create a TUI similar to Terminal.GUI. 

- SDL2 - https://github.com/libsdl-org/SDL

Used for input, rendering the framebuffer, audio, etc.
