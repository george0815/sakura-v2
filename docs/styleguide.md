- Hardware components and concepts are all caps (ex. CPU, PPU, BUS, X, S, P, etc)
- Hardware components filenames are all caps
- Component folders are all caps


- Local variables/variables declared in functions/args/params are snake case
- All other folders are snake case
- All other filenames are all snake case 

- Functions, classes are pascal case
- variables declared in namespace scope/inline variables are pascal case
- Class fields/variables are pascal case
